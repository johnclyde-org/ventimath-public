# Germany TST — German IMO Team Selection Tests

## Contest Owner

**Bundeswettbewerb Mathematik / German IMO committee**. The selection
program (AIMO and VAIMO rounds, earlier multi-test formats) picks
Germany's IMO team.

## Contents

- `aops/c{ID}.json` — raw AoPS community category captures (the
  `fetch_category_data` API response for each per-year collection;
  problem statements are BBCode in `post_data.post_canonical`).
  `c3300.json` is the tree root; the 27 per-year collections cover
  1977–1978 and 2002–2026 (c5064–c5075, c133020, c315214, c1125737,
  c1126247, c1127095, c1127948, c1128795, c1128851, c3086503, c3394976,
  c3624056, c3624057, c3923034, c4474284, c4842232).

## Source

- AoPS community tree: https://artofproblemsolving.com/community/c3300
  (per-year collection URLs are `.../community/c{ID}` with the IDs above).

## Attribution

Problems are the property of the German IMO selection program. English
statements in the AoPS captures are community translations of the
German originals.
